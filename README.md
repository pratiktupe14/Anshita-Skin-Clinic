# Anshita Skin Clinic (अंशिता स्किन क्लिनिक)

Official website for **Anshita Skin Clinic**, Kolhapur — dedicated to comprehensive dermatological care, clinical dermatology, cosmetology, and aesthetic skin treatments.

---

## 🌟 Features

- **Responsive Design:** Mobile-first, fully responsive layout built with clean modern CSS.
- **Treatment Showcase:** Detailed sections for acne, pigmentation, anti-aging, laser therapy, and hair loss treatments.
- **Interactive Elements:** Smooth navigation, sticky header, mobile drawer menu, FAQs accordion, and review carousel.
- **Quick Contact Integration:** One-click WhatsApp consultation, phone dialer, and contact inquiry form.
- **Location & Google Maps:** Easy directions and clinic hours for visitors in Kolhapur.

---

## 🚀 Getting Started

No build tools or package managers required. Simply run locally using any static web server:

### Option 1: Python
```bash
python -m http.server 3000
```
Then open `http://localhost:3000` in your web browser.

### Option 2: Node.js (npx serve)
```bash
npx serve .
```

### Option 3: Direct Browser Launch
Open `index.html` directly in any modern browser.
